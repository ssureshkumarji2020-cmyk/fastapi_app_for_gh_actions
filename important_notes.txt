CI/CD : Continuous Integration and Continuos Development

This will be important and main things for Devops
whenever pushing the code for any commit happening then automatically run the test cases, linting (writing format, styling guide), the application can build automatically and push it to repository. This is the purpose we are using github actions.. and it is one kind of automation..

If we plan to merge the code to main branch then initially needs to do some setup, like UAT, linting is okay and then build the image.. once builded successfully then we can push it to repository.

We are having an application, whenever there is a push or pull request to any of the branches then UAt to be done.. if so then we have to write a workflow.. like steps by steps.. these things should be under .github folder.. and crate a workflow folder. under that we have to create a workflow in .yaml file. like .githup\workflows\unitest.yaml
